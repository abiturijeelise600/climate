# Climate Forward

A React + Vite climate-awareness project with educational climate information, a rough illustrative emissions estimator, and local climate-action pledges.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

## Notes

- No database or backend is used. Pledge choices are stored in the browser's local storage.
- The estimator uses illustrative factors only; it is not a complete footprint calculation or official measurement.
- The learning links lead to the IPCC and United Nations climate resources.
